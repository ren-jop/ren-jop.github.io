About me

I’m Ren. I build software and hardware to understand how things work and make tools I want to keep using.

What I’m building

I’m working on three native macOS tools: Planner uses Apple Calendar for time blocks, Focus runs the session, and Deadlock protects time for sleep and work.

My Rust work started with Oxide Keys, a Pico W handheld with a custom four-layer PCB, and Descent: Null, a cave survival game built with Bevy.

Each project has its own notes and source code in the project index.
