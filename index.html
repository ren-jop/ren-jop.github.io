Hi, I’m Ren.

I like building software and hardware that I actually want to use. Most of my recent work is native macOS software and Rust.

I started learning Rust by making two very different things: Oxide Keys, a handheld with a custom PCB, and Descent: Null, a cave-survival game in Bevy. More recently I’ve been making small macOS tools for planning, focus and blocking distractions.
