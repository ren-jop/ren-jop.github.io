Working method

AI is in the loop, not the headline.

I use AI heavily because it shortens the distance between a problem, a hypothesis and something I can test.

Build against reality

I prefer a real build, physical prototype or playable interaction loop over speculative architecture. Compiler output, runtime behaviour and documentation decide whether an idea survives.

Narrow the search

I use AI to inspect build errors, compare implementation options, synthesise technical documentation and generate debugging hypotheses.

Keep context durable

I use it to maintain project handoffs, roadmaps, notes and study material so long-running work can continue without reconstructing every decision.

Source of truth

Generated output is a proposal. Code that compiles, runtime behaviour, datasheets, measurements and actual interaction still determine what ships.
