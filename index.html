How I work

The common thread is reducing ambiguity: one owner for important state, narrow interfaces between components, and evidence from the actual runtime.

01

One owner per state

Calendar state belongs to EventKit. Session state belongs to Focus. Enforcement state belongs to Deadlock.

02

Make failures inspectable

Logs, status commands, build checks and explicit operational paths matter as much as the happy-path UI.

03

Validate against reality

Compiler output, runtime behavior, hardware docs and measurements outrank speculative architecture.

Reproducible previews

Clone, build, run.

The macOS projects keep the install path in-repo and validate the actual source path in CI instead of hiding setup behind manual steps.
