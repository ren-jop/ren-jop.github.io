Engineering approach

The common thread across the projects is reducing ambiguity: one owner for each piece of state, explicit system boundaries, and verification against real behavior.

01

One source of truth

Do not mirror state unless there is a concrete reason. Planner uses EventKit; Focus owns session history; Deadlock owns enforcement state.

02

Small boundaries

Prefer narrow interfaces between components. Local IPC is easier to reason about than letting every app own privileged behavior.

03

Build against reality

Compiler output, runtime behavior, hardware documentation, measurements and playtests outrank speculative architecture.

04

Make operations visible

Installation paths, privileges, data locations, status and failure modes should be inspectable instead of hidden behind polish.

Installable previews

The macOS repos now build from a fresh clone.

Focus, Planner and Deadlock keep their source, install path and uninstall behavior in the repository. Deadlock also documents its privileged components and cooldown explicitly.
