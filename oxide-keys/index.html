Oxide Keys

A handheld mini-game console I built while learning embedded Rust, using a custom four-layer PCB and a Raspberry Pi Pico W.

Why I made it

I wanted to learn Rust somewhere the compiler was not the only thing that could go wrong. Designing the hardware made me deal with GPIO, datasheets, display timing, power, physical controls and debugging all at once.

The hardware

The handheld uses eight mechanical switches, RGB underglow, a rotary encoder and a small SPI TFT. I designed the four-layer PCB in KiCad and built the enclosure around it.

Hardware and CAD

These are some of the PCB and enclosure views from the Oxide Keys build.

The firmware

The firmware is no_std Rust on the RP2040 using the Rust HAL ecosystem. I built a small launcher and simple games including Pong while learning how the display and controls should be structured.

What mattered most

The best part of the project was getting a PCB I designed myself fabricated and working. It turned reading documentation and datasheets into something much less abstract.
