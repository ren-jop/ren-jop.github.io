Oxide Keys

Oxide Keys is an embedded Rust handheld console project by Ren Jopson using Raspberry Pi Pico W hardware, mechanical switches, RGB lighting and a small display.

Project focus

Oxide Keys explores embedded Rust through a physical handheld device: eight mechanical switches, a rotary encoder, RGB underglow, a display and firmware targeting RP2040 hardware. The project combines PCB/hardware design with Rust firmware development.
