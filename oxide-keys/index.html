Oxide Keys

A physical handheld built to learn embedded Rust by making firmware target hardware I designed rather than a generic development exercise.

What it explores

The hardware combines a Raspberry Pi Pico W, eight mechanical switches, a rotary encoder, RGB underglow, a small display and a custom multi-layer PCB.

The firmware work focuses on no_std Rust, HAL/PAC usage, GPIO, display/input integration and understanding the RP2040 from the datasheet upward.

AI in this project

AI is used to accelerate datasheet synthesis, compare embedded-Rust approaches, sanity-check pin/interface assumptions, explain compiler and HAL errors, and turn hardware/firmware progress into concise engineering documentation. The actual electrical constraints, register behaviour and board decisions are checked against source documentation and the physical design.
