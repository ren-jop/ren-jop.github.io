Oxide Keys

A handheld built to learn embedded Rust against hardware I designed: custom PCB, mechanical inputs, display, lighting and RP2040 firmware.

Engineering problem

The goal was to learn Rust below the desktop layer by making firmware work against a real device rather than treating embedded development as an isolated tutorial.

Hardware

The design combines a Raspberry Pi Pico W, eight mechanical switches, per-key RGB underglow, a rotary encoder and a small SPI display on a custom four-layer PCB.

Firmware

The firmware uses no_std Rust with rp2040-hal/embedded-hal, direct hardware documentation and peripheral integration. A Rust launcher handles input and game selection, with small games such as Pong used to validate the device loop.

What this project tested

PCB design, datasheet reading, GPIO and SPI integration, HAL/PAC boundaries, firmware debugging and the discipline of validating assumptions against physical hardware.
