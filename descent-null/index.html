What it does

Movement includes gravity, collisions, coyote time and jump buffering, while procedural caves are generated around a guaranteed reachable path.

Survival systems include injuries, bleeding, fractures, hunger and thirst; inventory and crafting were simplified after testing to keep the feedback legible.

AI in this project

AI is integrated into implementation review, debugging, gameplay-system planning and regression analysis, then changes are validated by running the game and judging the actual interaction.
