Planner

Planner is a native macOS command center by Ren Jopson that connects Apple Calendar, Focus session history and Deadlock enforcement.

What it does

• Apple Calendar / EventKit remains the sync and scheduling backend
• Dashboard for upcoming time blocks, goals, exams and recent work
• Calendar event editing and Focus launch from scheduled blocks
• History can compare planned duration with actual focused work
