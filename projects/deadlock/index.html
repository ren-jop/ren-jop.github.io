Deadlock

Deadlock is a native macOS enforcement tool by Ren Jopson for sleep schedules, distraction blocking and focused computer use.

What it does

• Root-enforced sleep windows with IOKit wake detection and pmset sleepnow
• Timed distraction blocking with a native menu-bar interface
• Designed for low idle CPU and event-driven enforcement
• Integrates with Focus so a work session can automatically enable distraction protection
